Cranpose with game engines

Cranpose renders with Bevy and with Godot on one GPU device in your browser: each engine's valley inside a Cranpose layout, and a Cranpose HUD over each engine's camera. The Bevy examples run on WebGPU where the browser has it (Chrome, Edge, Safari 26) and on WebGL2 elsewhere, with a plain sky in place of the atmosphere. Godot's web export runs on WebGL2, and Cranpose runs inside it as a Godot extension on Godot's own WebGL2 context.

Walk with WASD or the arrow keys, run with Shift, and drag to look. On a phone, drag to look and use the stick to walk and turn. Source, desktop downloads and project templates: github.com/samoylenkodmitry/cranpose-engines.
